# Machine-tested runs — not evidence

Every run in this folder was driven by a machine: a model playing a
simulated student with a made-up persona, against the real models and
server. They were useful for finding bugs in the mechanisms (several were
found and fixed this way), and some of them failed or came out worse than
hoped.

They are set aside, counted neither for nor against Versa's thinking style
(docs/THINKING_STYLE.md). What a thinking style is, and whether Versa picks
it up, is to be shown with real learners.

Moved here 2026-10-01. The matching rows in the database's `evidence_records`
log stay as they are (append-only, invariant 11); nothing in the app reads
them as proof.
